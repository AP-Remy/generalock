# 🔐 Generalock

Générateur de mots de passe simple, rapide et sécurisé — directement dans le navigateur, sans installation.

🔗 Démo en ligne : https://ap-remy.github.io/generalock/

## Fonctionnalités

- Génération de mots de passe aléatoires (minuscules, majuscules, chiffres, symboles)
- Longueur ajustable de 4 à 32 caractères via un curseur
- Aléatoire cryptographiquement sûr grâce à l'API Web Crypto (`crypto.getRandomValues`)
- Copie du mot de passe en un clic dans le presse-papier

## Technologies

- HTML / CSS / JavaScript (vanilla, sans bibliothèque externe)
- Web Crypto API pour une génération aléatoire sécurisée
- Hébergé sur GitHub Pages

## Lancer en local

Pour Cloner le dépôt :
   ```bash
   git clone https://github.com/ap-remy/generalock.git
   ```
